# Security policy

LeanBun is experimental and currently supports registered fixtures only. Do not use it as a privileged installer or point mutation commands at production projects.

For a suspected vulnerability, use GitHub's private vulnerability reporting feature when enabled. Do not include credentials, private repository contents, personal filesystem paths or production package data in a public issue.

Security reports should include the LeanBun version, platform, minimal fixture-only reproduction and observed fail-open or integrity impact.
