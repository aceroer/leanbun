== 证据等级

[cols="1,3"]
|===

行为都不能自动视为 1.3.14 已验证能力。升级时建立新目录并重新执行验证，不覆盖本记录。

== 本机复核命令

[source,shell]
----
bun --version
bun --revision
bun --help
bun run --help
bun test --help
----

这些命令只读取 runtime 信息。不要在检查活动 Lean 项目时用 `bun install`、`bun update`、`bunx` 或
未关闭 auto-install 的脚本作为文档验证方式。

== 升级检查表

. 新 Bun 二进制写入独立 provenance；
. 保存 `--version`、`--revision` 与 relevant help；
. 重新检查 File、CryptoHasher、Spawn、SQLite、Test、Compile 官方页面；
. 运行 hash/spawn/SQLite 本机 smoke；
. 运行 LeanBun adapter、non-mutation 与 concurrency tests；
. 生成新的 `doc/bun-v<version>/`；
. 方案审查通过后才修改默认 runtime gate。
