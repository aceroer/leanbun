== LeanBun 使用边界

`leanbun-approval-macos` 只调用 `getrandom::fill(&mut [u8; 32])`，每个 terminal-approved session 产生一次 256-bit OS
random nonce。原始 nonce 不进入 prompt、JSON、日志、环境变量、参数或公开 getter。

nonce 先做 SHA-256，再与 terminal device、owner/effective UID、foreground process group 和 controlling-session identity
形成第二层 session binding digest。challenge 只持有 binding digest。

随机源错误直接 fail closed；不回退到时间、PID、UUID、`/dev/urandom` 路径读取或伪随机算法。

== macOS backend

0.4.3 在 `target_os = "macos"` 使用 `getentropy` backend；公开 `fill` 保证成功时完整初始化目标 slice。LeanBun 不启用
custom、WASM、RDRAND 或 unsupported backend。

完整来源、hash 与 tag 限制见 xref:SOURCES.adoc[SOURCES.adoc]。
