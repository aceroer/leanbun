== LeanBun 使用 API

`leanbun-approval-macos` 只调用：

* `rustix::process::geteuid`：当前 effective UID；
* `rustix::process::getpgrp`：当前 process group；
* `rustix::process::getsid(None)`：当前 process session；
* `rustix::termios::tcgetpgrp`：terminal foreground process group；
* `rustix::termios::tcgetsid`：controlling-terminal session。

所有 terminal API 直接接收 Rust `AsFd`，不传 raw fd，不在 LeanBun 内编写 unsafe FFI，不 spawn `/bin/ps`、`stat` 或
其他 PATH 命令。

== Proof 条件

只有以下事实同时成立，terminal observer 才发布 `ReadyForChallengeResponse`：

. stdin/stderr 是同一稳定字符设备；
. device owner UID 等于 `geteuid`；
. `getpgrp` 等于 `tcgetpgrp(stdin)`；
. `getsid(None)` 等于 `tcgetsid(stdin)`；
. proof 前后的 terminal device identity 没有漂移。

该 decision 仍保持 execution authority `Withheld`，不读取 response、不生成 grant。

== 本机验证

普通非 TTY Codex 进程得到 `DeniedNonInteractive`。在隔离 PTY 中，owner/effective UID、process/foreground PGID 与
process/terminal SID 三组值均一致，得到 `ReadyForChallengeResponse`，authority 仍为 `Withheld`。
