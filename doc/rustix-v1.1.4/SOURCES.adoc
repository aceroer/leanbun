== License 与信任限制

上游声明 `Apache-2.0 WITH LLVM-exception OR Apache-2.0 OR MIT`。`v1.1.4` 是 annotated tag，但本地 `git tag -v`
确认 tag 没有签名。因此 provenance 由 tag object、commit、Cargo registry checksum 和 relevant source hashes 合取，不能声称
已获得签名发布证明。

rustix 内部按平台使用 unsafe/libc binding；LeanBun 依赖其公开 safe API，并继续禁止自身 crate 的 unsafe code。升级必须建立新的
版本目录、重新核对 macOS API、锁文件 checksum、source diff、许可证与 PTY/non-TTY tests。
