= LeanBun Historical Crate Disposition Decision M47
:toc: left
:sectnums:

== Decision status

This disposition is fixed before changing Cargo default membership. M44--M46 established that none
of the six mainline roots transitively reaches the five historical crates. M47 changes build/test
selection only; it does not move, delete, rewrite or deprecate historical source or evidence.

== Mainline default closure

The default Rust members are the complete Bun-managed package lifecycle closure:

* `leanbun-core`;
* `leanbun-codec`;
* `leanbun-evidence`;
* `leanbun-lock`;
* `leanbun-lake-bridge`;
* `leanbun-resolver`;
* `leanbun-store`;
* `leanbun-generation`;
* `leanbun-build`;
* `leanbun-managed`.

The default `cargo test` and `cargo clippy` selection must compile exactly that closure. All fifteen
crates remain workspace members so Cargo metadata, dependency auditing and explicit historical tests
continue to see the retained research code.

== Verification contract

`./scripts/rust-dev check` validates default members only. `./scripts/rust-dev historical-check` (also
available as `./scripts/dev historical-check`) explicitly runs Clippy and tests for all five retained
historical packages. The architecture guard must reject a default set that contains a historical
crate or omits any mainline closure crate.

The standard Cargo source-build entry is `cargo test` from `rust/`. It uses repository-relative path
dependencies and public Cargo dependencies only; it must not require production credentials,
Developer ID/notarization identity, Keychain state or an embedded personal filesystem path.

== Non-actions

M47 does not archive crates outside the repository, move them under a new directory, add Rust
deprecation attributes, delete tests, change canonical formats, or weaken the all-workspace
dependency audit. A future removal requires a separate evidence-retention decision.
