= LeanBun M5 Reuse Signal and Recovery
:toc: left
:sectnums:

== 状态

M5 第十六阶段把显式 reuse transaction 纳入 signal 与 stale-running recovery。Reuse 不启动 Lake，因此没有
process group；但仍必须保护其长时间全量哈希、execution record 与 project/image lock 生命周期。

== Signal 协议

CLI 捕获 `SIGINT`/`SIGTERM` 并设置 AbortSignal。若信号在锁前到达，不创建任何状态；若在 `running` record
发布后到达，不在文件哈希中间硬退出，而是在当前只读重验到达安全点后：

. 记录 `REUSE_TRANSACTION_CANCELLED` 与触发信号；
. 原子终结为 `failed`，`failureStage=reuse-verification`；
. 释放精确所有权 lock；
. 返回失败，不运行 Lake，不自动转入正常 build。

真正的进程崩溃、`SIGKILL` 或主机中断仍可能留下 `running`。显式 `build recover` 现报告
`executionKind=reuse`，沿用协调 PID、cwd process、binding、attestation、project protected records 和全部
dependency artifact 审计；成功恢复只会终结为 failed，并额外产生 `REUSE_EXECUTION_RECOVERED`。
