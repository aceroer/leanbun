= LeanBun M5 Controlled Build Execution Record
:toc: left
:sectnums:

== 状态

M5 第九阶段已把受控构建报告提升为独立的短生命周期 execution record。只有完整 attestation 重验通过、
sandbox 已准备好且 Lake 即将启动时才创建记录；preflight 拒绝或尚未执行的请求不会生成记录。

记录位于开发 state root 的 `executions/<uuid>.json`。它是操作证据，不写入 project binding，且
`BuildAuthorizationFacts` 不读取它，因此不能被重放为构建许可。

== 状态转换与落盘协议

[source,text]
----
approved + sandbox prepared
  -> running
       -> completed
       -> failed
----

`running` 和终态都采用同目录协作锁、随机临时文件、文件 `fsync`、mode `0444`、原子 rename、目录
`fsync` 与立即回读校验。UUID 冲突、重复终结、终态/结果不一致、symlink store 和超出 state root
全部默认拒绝。状态只能转换一次。

记录绑定 project ID/path、target、Image ID、binding/attestation/profile SHA-256、协调进程 PID、构建前
dependency artifact hash、项目非写区 hash/count 与开始时间。终态再记录 Lake exit、构建后 artifact hash/count、项目非写区、binding、
attestation 和 provider inspection 是否稳定。异常消息最多保存 1024 字符。

整个 state root 同时加入 sandbox protected roots；若错误配置使它与 `.lake/build`、`.lake/config` 或
`.leanbun/tmp` 重叠，构建会在启动前拒绝。
