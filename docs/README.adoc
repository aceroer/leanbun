== 文档维护规则

* README 只描述当前能力、限制和入口，不复制完整里程碑编年史；
* authority 与 roadmap 分开，架构意图先于代码移动；
* milestone 文档完成后保持历史语义，不用后续状态覆盖旧证据；
* 新的本机绝对路径、凭据或私有 provider 信息不得进入公开文档；
* 提交前运行 `./scripts/check-docs` 和 `./scripts/check-public-source`。
