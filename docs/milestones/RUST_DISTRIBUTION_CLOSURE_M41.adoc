== Result

M41 Phase C 的 development distribution closure 已完成。源码、Bun fork 接线、provenance、versioned install 和
installed-binary replay 现在均有可引用边界；正式 Apple distribution signing 仍关闭，因为本机没有任何有效
codesigning identity，也没有 `leanbun-notary` keychain profile。

这一区分是强制的：本阶段完成可复查的 unsigned development package，不把 ad-hoc signature 描述为 Developer ID，
也不把 Gatekeeper 的预期拒绝描述为发布成功。

== Apple signing evidence

本机探针结果：

* `security find-identity -v -p codesigning`：`0 valid identities found`；
* `xcrun notarytool history --keychain-profile leanbun-notary`：profile 不存在；
* Mach-O signature：`adhoc,linker-signed`，没有 TeamIdentifier；
* `spctl -a -vv -t install <installed-binary>`：退出码 3，结果 `rejected`。

因此没有执行 `codesign --sign <Developer ID>`，也没有向 Apple 提交 notarization。此处不存在可安全推断或代建的身份。

在此之前：真实外部项目 adoption、任意远端解析、公开安装包和 production-ready 声明全部保持关闭。
