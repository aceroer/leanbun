== Clean-checkout validation

The authoritative checkout was detached at the source baseline under the short macOS path
`/private/tmp/leanbun-m48-source`. A first nested checkout was rejected for absolute override escape;
after rebuilding its provider state it exposed the macOS Unix-socket path-length limit, so it was not
used as evidence. The short checkout then passed:

* 208 Bun/Lean logical tests with 1770 assertions;
* 117 default-mainline Rust tests, with the one provider test intentionally ignored in the default run;
* 79 explicit historical-crate tests;
* the provider test explicitly, one passed and none ignored;
* all six installed-binary fixture paths: lake-basic, managed dependency, Mathlib, negative matrix,
  concurrent history and Reservoir loopback.

No public registry discovery or external project was used. Public Cargo cache and the configured
read-only local Lean provider were build inputs; all generated state remained inside the detached
checkout.

== Upgrade and rollback

The retained `0.11.0-m42-dev` binary was accepted only at its exact SHA-256
`f6416817e2c893b311245c65f2a54668b0a633e028de1fe31e05701322670359`. M48 became active with M42
retained as previous; rollback restored M42, retained M48, and executed the restored binary to verify
its version. The protected M31 fixtures and frozen M42 history document remained byte-identical.

== Patch and privacy closure

Seven redacted `git format-patch` files reconstruct the paired Bun tree from the exact upstream base.
A scratch `git am` replay produced tree `d390a478a2ec5462b627e8e4e627fa583c223073`. Author email was
removed from the public patch headers; personal local-provider configuration remains Git ignored.

`scripts/check-public-source` rejects personal home or mounted-volume absolute paths and checks the patch
count, architecture contract and local-provider ignore rule. The public export replaces the local
checkout path in the frozen M42 concurrent-history transcript with
`<registered-fixture-repository>`. Historical references to the original M42 SHA-256 remain internal
baseline identities; the public checker separately binds the redacted disclosure copy.

== Excluded claims

public Reservoir metadata trust or production project adoption. No remote was pushed during closure.
