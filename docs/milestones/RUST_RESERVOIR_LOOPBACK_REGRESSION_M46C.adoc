== Result

M46 Phase C is complete as `0.18.0-m46c-dev`. The pure M46A/M46B model is now exercised by a
durable controller in `leanbun-managed`, but only against the repository-owned file-loopback
fixture. No public Reservoir discovery, external project mutation or network transport was added.

== Durable closure

`run_reservoir_loopback_regression_v1` canonicalizes the LeanBun repository and exact registered
fixture, then creates a private run below `.leanbun-dev-rust/reservoir-m46c/runs`. Candidate V1 lock
and companion bytes plus pending, verification, authorization, audit and activation evidence are
immutable `0400` files. The two verification records bind successful strict lock/companion
round-trips before first activation and rebind activation. `active.record` is the only mutable commit
point and is replaced by file sync, atomic rename and directory sync.

The regression proves:

* the first candidate is durable and reviewable while active is absent;
* repeated old observations are stable;
* ordinary old-to-new rebound publishes evidence but leaves active bytes unchanged;
* a subsequent old observation records old-new-old oscillation;
* metadata-only and same-commit content drift remain distinct typed outcomes;
* disappearance leaves the old exact lock and companion replayable;
* explicit rebind binds the exact M46B authorization and prior pending record;
* new frozen replay and rollback to the retained old activation do not read the registry.

One completed run contains ten audit records and nine file-loopback registry observations. Frozen
replay and rollback finish with the same observation count. The final immutable result records
`ordinary-rebind=rejected`, `network-access=none` and `public-discovery=closed`.

== Remaining boundary

M46 is now closed through registered regression. This is not a production Reservoir client. Public
registry discovery, credential policy, network fetching and external-project activation require a
separate future authorization milestone. The next roadmap milestone is M47 historical crate
disposition; it must not delete historical evidence.
