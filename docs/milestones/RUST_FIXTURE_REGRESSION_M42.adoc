== Result

M42 Phase A 已把 `lake-basic` 从一次性 milestone acceptance 扩展为可重复的日常回归入口：

[source,shell]
----
leanbun fixture-regress "$LEANBUN_REPOSITORY"
----

该命令仍只接受一个仓库路径，不接受外部 project 参数。它复用 M37 已验证的 generation publication、precommit
fault、recovery、intentional Lake failure、两次 supervised build、image publish/reuse 与 rollback 实现，不复制另一套构建逻辑。

== Run model

每次运行从时间、进程和进程内 nonce 形成独立 SHA-256 run ID。隔离执行根为：

----
.leanbun-dev-rust/generation-fixture/m42-regression/runs/<run-id>/
----

该路径仍位于 `LeanGenerationManagerV1` 的既有 `generation-fixture` writer boundary。回归完成后整个 run root 被清理；
若路径已经存在则 fail closed，不复用未知状态。

成功摘要发布到：

----
.leanbun-dev-rust/regression/
  latest.record
  records/<run-id>.record
----

历史 record 使用 `create_new`、file sync、`0400` chmod 和 directory sync，不能覆盖。`latest.record` 是 `0600`
mutable pointer，通过同目录临时文件和 atomic rename 更新，并绑定最新 record SHA-256。

== Remaining M42 roadmap

Phase A 只闭合 dependency-free `lake-basic` 快速回归。后续按顺序推进：

. Phase B：已由 xref:RUST_MANAGED_DEPENDENCY_REGRESSION_M42.adoc[Managed Dependency Regression M42 Phase B]
  把 `lake-managed-dependency` 的 adopt/build/explicit update/fault/recover/rollback 变成可重复 run；
. Phase C：已由 xref:RUST_MATHLIB_REGRESSION_M42.adoc[Mathlib Regression M42 Phase C]
  加入 `mathlib-project` 九包完整闭包回归；
. Phase D：已由 xref:RUST_NEGATIVE_FIXTURE_REGRESSION_M42.adoc[Negative Fixture Regression M42 Phase D]
  登记 malformed/path escape/hash drift/cycle/missing package 负 fixture；
. Phase E：已由 xref:../../RUST_CONCURRENT_HISTORY_REGRESSION_M42.adoc[Concurrent History Regression M42 Phase E]
  完成并发回归调度、失败 terminal record 与历史记录审计/保留策略。

M42 路线现已闭合。任何后续 milestone 都不得修改 M41 frozen records，不得隐式放宽真实外部项目入口。
