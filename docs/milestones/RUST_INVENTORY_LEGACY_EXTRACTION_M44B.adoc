== Result

M44 Phase B is complete as `0.14.0-m44b-dev`. The historical checkout inventory, dependency drift and canonical inventory snapshot model has moved into `leanbun-inventory-legacy`. The mixed `leanbun-package` crate and its temporary lock re-export have been removed from the workspace.

Together with xref:RUST_LOCK_EXTRACTION_M44A.adoc[M44 Phase A], this closes M44's package-model physical separation. The current lock model and historical inventory model no longer share a crate, public namespace or mainline dependency closure.

== Final crate boundary

`leanbun-lock` depends only on `leanbun-core`. It owns exact requested/resolved sources, `LeanBunLockV1`, package graph identity, path provenance and the Bun final-path decision.

`leanbun-inventory-legacy` depends only on `leanbun-core` and `leanbun-evidence`. It owns checkout observations, provider comparison, dependency drift and inventory snapshot identity. Its only direct consumers are the historical `leanbun-plan` and `leanbun-approval-macos` crates.

The six mainline roots directly depend on `leanbun-lock` and cannot reach inventory legacy, plan, state, approval or macOS ACL code. The crate checker rejects any workspace that contains both `leanbun-package` and `leanbun-inventory-legacy`.

The literal digest domain `leanbun-package-graph-v1` remains inside the V1 lock implementation. This is an on-wire identity constant, not a crate dependency, and changing it would break M31 compatibility.

== Dependency enforcement

The M44B graph contains 14 workspace crates: `leanbun-inventory-legacy` replaces the removed mixed package crate. Automated policy now verifies:

* every mainline root directly imports `leanbun-lock`;
* no mainline closure reaches inventory legacy or another historical policy crate;
* inventory legacy cannot depend on lock;
* mixed package and inventory legacy cannot coexist;
* the moved lock and snapshot files retain their pre-refactor hashes;
* the API census resolves to the new physical source paths.

The dependency negative matrix now contains nine tests and thirteen assertions.
