= LeanBun M5 Build-Time Attestation Re-verification
:toc: left
:sectnums:

== 状态

M5 第五阶段已实现构建时独立重验。命令只在 project binding、target allowlist 和 sealed attestation 的
静态门全部通过后，重新读取完整 provider source/config/artifact 字节：

[source,shell]
----
leanbun build verify <project> <target>
----

返回 `approved` 只表示本次进程中的证据合取成立；report 固定保留 `buildExecution: not-attempted`，不创建
持久 permit、不启动 Lake，也不授予其他进程可复用的权限。普通 `build preflight` 仍保持快速、只读且
`valid-unverified`。

== Re-verification protocol v1

. 完成普通 preflight：project ID/path、manifest、toolchain、provider、binding、image 和 target 全部匹配；
. 从真实文件 descriptor 重新计算 canonical source/config/dependency/artifact tree；
. 比较 Image ID、完整 identity、dependency tree、artifact tree/count 与 missing-root policy；
. 比较当前 provider state、registry SHA-256 和 override SHA-256；
. 完整取证结束后再次读取项目、provider、binding 与 attestation；
. 要求项目 inspection 不变、binding SHA-256 不变、attestation SHA-256 不变；
. 全部成立时才设置本进程内 `attestationVerified=true`，否则返回
  `ATTESTATION_REVERIFICATION_FAILED` 与 `ATTESTATION_UNVERIFIED`。

未批准 target、binding/manifest 漂移或无效 attestation 会在完整树哈希之前拒绝，避免对无资格请求执行
6.82 GB 重验。
